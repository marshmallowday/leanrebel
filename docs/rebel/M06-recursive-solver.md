## Explicit error and finite-iteration allocation

For each parent let C_E be the actual sum of its error coefficients and C_T the
sum of its finite-time coefficients, including the administrative chance root.
At requested accuracy tau > 0 the existing allocator is used without modification:

    numerical allowance delta = tau / (4 * (abs(C_E) + 1))
    parent child-loss allowance lambda = tau / 8
    remaining round budget r = tau - (C_E * delta + 2 * lambda) > 0
    rounds T = floor_nat((abs(C_T) / r)^2) + 1

A live factual child with joint-law positive mass floor m is requested at
accuracy m * lambda. This supplies the private-type/reference-query loss after
public splicing and zero-own-reach completion. The actual parent's finite bound
retains every term:

    error <= C_E * delta + C_T / sqrt(T) + 2 * lambda <= tau.

T is positive and finite before averaging or private sampling. An infeasible
arbitrary input does not create an empty iteration carrier, but no accuracy is
claimed for it. Increasing T does not erase fixed unallocated numerical error.
Each recursive parent explicitly allocates positive numerical and child tolerances.

The numerical contract is separate from computation. A family must satisfy its
stated absolute error bound at every requested modeled root/query. The concrete
pbsRecursiveAllocatedNoise uses the entire allocated allowance, with its bound
and strict positivity proved. This is a nonzero numerical control, not evidence
that an arbitrary learned network meets the contract. These are classical
real-valued definitions, not an executable floating-point refinement or a claim
