## 非自明な縦断例と負例

### 二段階 HiddenTypes

chance が joint な Bool × Bool を標本化し、その後二人が二段階の同時手番を行う。
各人には自分の type と public signal だけが渡される。

- 相関法則 (00/11) と反相関法則 (01/10) は両方の周辺分布が同じだが、
  同じ情報局所方策の canonical 累積報酬評価は **2 と0** に分かれる。
  周辺分布の任意の直積で joint PBS を定義する設計を棄却する診断である。
- 異なる最初の joint action により同じ物理状態・圧縮 view に合流しても、
  full AOH は過去の自分の行動を区別する。historyFintype に tree-shaped を要求しない理由である。
- 特定方策で到達確率0の合法な履歴にも、二つの合法な後続選択が残る。
  実際の継続報酬は **+1 と−1** となる。確率0を理由に分岐を消さない。
- 同じ自分の AOH で相手の type だけが異なる場合、情報局所方策から相手の秘密へアクセスできない。

### 小さい Liar's Dice

各人1個・3面・最上面が wild、bid は数量1/2と3面の辞書順で6種類。
全ての合法な raise と challenge をモデル化する。冒頭の call は違法、最大 bid の後は call のみ。
wild の一致は二重に数えない。二人の私的 dice の joint prior は任意の FinDist として保持する。

全合法履歴の停止上限は8。例示方策は任意の opening bid の後で challenge するもので、
ゲーム自体をその方策だけへ縮小していない。利得は勝者+1・敗者−1、途中は0。
`LiarsDicePayoff.potential_step` と `cumulative_eq` が実遷移を累積利得へ接続し、
`rootValue_formula` が完全 AOH 方策の canonical policyValue を chance prior の期待値に結び付ける。
`testPrior_value` は **+1/2**、`testPrior_opponent_value` は **−1/2**、
`false_bid_loses` は **−1**。合法手・停止・零和性は例示方策以外にも成立する。
全 dice 数/面数への一般化と C++ 実装との形式的 refinement は M10 に残る。

### 原典のサイコロ例

ObservedDice は実際の chance Protocol で四つの6面 dice を joint に標本化する。
公的な二つの目だけを固定した canonical history fiber と Fin 6 × Fin 6 の全単射、
さらに player 2 の私的な目を固定した fiber と Fin 6 の全単射を構成する。
`public_card = 36`、`second_card = 6` は単に別のタプル集合のサイズを数えたものではない。

`second_not_perfect` が元の非完全情報ゲームを証明する一方、
別の全目公開モデル `revealingSignals` では全 AOH が実際の履歴を一意に定める。
CommonKnowledge では全員が全目を privately 観測し public signal は一定という第三の観測モデルを使う。
同じ public trace の異なる履歴が、個人識別不能関係の有限鎖では結ばれない反例を証明する。
元のゲームの観測を黙って変更して完全情報と呼ぶことはしていない。

### Figure 1a の変則じゃんけん

ModifiedRPS は payoff 表 `(0,-1,2; 1,0,-2; -2,2,0)` と確率 `(2/5,2/5,1/5)` を実装する。
既存 NFG→FOSG および hidden-phase FOSG→EFG 変換を適用し、
第2プレイヤーに第1プレイヤーの未公開選択を漏らさない sequential representation の
**全 behavioral policy に対する source-history law 保存**を `sequential_exact` で証明する。
`protocol_utility_law` が実際の Protocol 利得法則を payoff 表へ接続する。
表示された混合分布に対する全ての行/列の値が0であることも確認する。
Figure 1b の PBS/search の説明や全ゲームの均衡保存をこの結果だけで閉じない。
