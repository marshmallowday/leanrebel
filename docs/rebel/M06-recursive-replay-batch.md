## Dependency-ordered batch

PBSRecursiveReplay strengthens the actual recursive draw's model-mixture
law to each supported history using retained root prefixes. It then allows
arbitrary actual reweighting inside model support and derives the explicit
2B times unsupported probability error when domination is unavailable.
The unknown opponent remains the same on both sides; its probabilities need
not match the modeled opponent. Fuel is arbitrary, including a late horizon.

The parent consumer identifies a cfrDComposedChildProfile continuation with
the actual pbsRecursiveDepthDraw at its factual child PBS and the EXACT
positiveMassFloor * loss request used by its child table. This discharges
the profile correspondence for that concrete computed child, without a Nash
closeness or desired value-bound premise. Reweighting and private conditioning
within the factual child support remain valid. Zero-own-reach completion
preserves the whole unilateral run from the original initial history.

PBSRecursiveCarriedReplay then applies the supported identity to the actual
pbsRecursiveDepthResolver and canonical carried runner. The analysis-only
history-first kernel samples the average history, then the NATIVE conditional
private profile and its own saved MODEL posterior. It preserves the entire
next-state law outside the explicit support exception. Any later kernel may
read that state, and its error is charged under the actual incoming full-state
law rather than a separately averaged history distribution.

The late-value theorem keeps one private draw through stage.fuel + remaining.
A matching incumbent has zero signed replacement loss. That theorem explicitly
requires equality to the newly computed own policy; local Nash precision
does not discharge that premise. The separate concrete parent-table theorem
establishes replay for a precisely matched table computation.

## Scope boundary still requiring work

These theorems do not establish that every independently invoked native
resolver receives its parent's factual child PBS, rooted-model representation,
noise allocation and mass-scaled tolerance. The parent child conditions on
a live public event, whereas the saved model posterior is propagated from
the selected profile and conditioned on a public observation. Their equality,
including root transformations and live/terminal cases, must be proved before
substituting one for the other. The rational controls exhibit why it cannot
be asserted unconditionally.

Likewise, completion invariance from the initial history does not justify
pointwise equality on arbitrary off-path histories. The support defect has
not been proved small under every native recursive state law. A zero signed
local loss for a matching incumbent does not by itself prove the complete
fresh-resolve chain safe. No hidden actual history or unknown policy is added
to the deployed solver input; the history-first kernel is only proof-side.

This boundary is chosen for the semantic correspondence needed by the next
integration, not by file size. Small generic lemmas have been grouped with
actual solver/parent/carried consumers, examples and negative controls.
