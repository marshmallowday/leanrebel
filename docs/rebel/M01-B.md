## R1–R7 の判断と後続義務

### R1 — joint PBS と compact representation（M03）

本文§4の joint law とプレイヤー別の分布表現を同じものと定義しない。
public-history fiber 上の相関を保つ法則を参照意味論とし、chance、カード重複禁止、支持の制約を残す。
各プレイヤーの reach factor と固定 chance kernel による compact encoding が参照法則を表すことを
別定理にする。任意の周辺分布の直積から元の joint law を復元することはできない。
対応は `P-PBS-JOINT`、`P-PBS-MARGINAL`、`P-PBS-COMPACT`、PBS-* 親行。

### R2 — 情報・Bayes・ゼロ到達（M02–M03）

本文§3の AOH と既存 `InfoState` は自動的には一致しない。
`InfoSignals.PerfectRecall`、合法 menu の adequacy、public history 復元を実ゲーム上で証明する。
`bayesBelief` は有限な個人 information fiber、antichain、正の information mass を要求する。
これは joint PBS 構築済みという意味ではない。正規化前の counterfactual reach、own reach、
実際の到達確率を区別し、ゼロ確率では除算の定義と後続定理の適用域を明記する。

### R3 — Theorem 1 と正規化拡張（M05）

本文p5と補遺F（p19–20）を照合した。simplex 上の supporting inequality、
正の cone 全体に対する凹関数の supergradient、不連続/非微分可能点を含む局所微分概念は別物である。
`f(x,y)=x/(x+y)`、`b=(1/2,1/2)`、`g=(1/2,-1/2)`、`z=(1/2,3/2)` では、
`f(z)=1/4` なのに `f(b)+g·(z-b)=0` となる。
M01-A の Lean 診断はこの supporting inequality の失敗と、simplex 正例、境界、
原点除外、midpoint Jensen の `1/3 < 3/8` を証明した。

従って「正規化拡張は一般に cone 全体で凹」という広い読み方は採用できない。
しかし、この有理数診断は実ゲームへの埋め込みでも、実数上の微分定理でもない。
`VAL-THEOREM1` は未証明・未反証のままにする。
まず相手固定の条件付き分布の下で type ごとの最適応答を一つの合法方策へ貼り合わせ、
simplex 上の主張を独立に証明する。その後、active branch の微分、一般化勾配、
境界点と off-path type の規約を原文と対照する。
脚注8の linear combination という表現にも、supergradient を保つ凸結合の係数条件が必要である。

### R4 — 理想記憶器の量化（M07）

Theorem 2 / Lemma 3 の学習回数N、solver反復T、深さを分離する。
本文の値誤差、補遺のある equilibrium policy に対する値、type-value vector の誤差を同一視しない。
理想的な記憶器の更新と実際のニューラル学習も別対象である。
query 集合の安定化には有限性、tie-break、更新後の sampling の条件が要る。
確率1、期待値、決定論的 fairness 条件付きを区別し、連続PBS全体を無限回訪問するとの
不可能な読み替えは行わない。counterfactual-zero と actual-zero の混同も禁止する。
無限サンプリングを扱う時点で測度論の確率法則を明示的に導入する。

### R5 — 有限反復誤差の項（M06）

出版本文 **p8** の Theorem 3、補遺 **p21** の再掲と **p22** の証明末尾は、
`delta*C1 + delta*C2/sqrt(T)` という形を印刷している。arXiv v2も同じである。
初期ROADMAPの「補遺の再掲だけ」という狭い記録を訂正した。
一方、補遺p21の基底ケースには `k1/sqrt(T)` が残り、Appendix I（p22）の
説明は `k1*delta + k2/sqrt(T)` の形である。

独立した代数的診断として、delta>=0、T>0、非負係数で

```text
e_0 <= q/sqrt(T)
e_(k+1) <= a_k*delta + b_k/sqrt(T) + c_k*e_k
A_0 = 0, B_0 = q
A_(k+1) = a_k + c_k*A_k
B_(k+1) = b_k + c_k*B_k
```

を仮定すると、帰納法により `e_d <= A_d*delta + B_d/sqrt(T)`。
実際、帰納仮定を非負の `c_k` 倍して第二式に代入し、delta項と反復誤差項を集めればよい。
従って delta=0 でも B_d が正なら有限反復項は消えない。
`test_error_recurrence.py` は有理数による合成・ゼロ誤差・ゼロ深さの対照例を確認する。
**この前提付き代数は solver がこの漸化式を満たす証明でも、元定理のゲーム反例でもない。**
係数の深さ依存、payoff 範囲、best-response metric と、各 subgame の誤差伝播を M06 で証明する。
原文を黙って修正して同名で証明したことにせず、原文・修正版候補・制限定理を別の子行にする。

原典引用の照合として、Burch/Johanson/Bowling, arXiv:1303.4441v4, p4 Theorem 2 は
`R_p^T <= Delta*|I_TR|*sqrt(A*T) + T*N_S*epsilon_S` の形である。
T>0で割ると探索反復項とcontinuation誤差項が独立に残る。
p5では通常の best response でなく counterfactual best response を要求している。
DeepStack, arXiv:1701.01724v3, p6 Theorem 1 の `k1*epsilon + k2/sqrt(T)` とも対照した。
同頁の action sparsification に関する保証の留保も、M10の action abstraction を無償の同値変換と
扱わない根拠になる。これらは定理文と近傍前提の一次資料確認であり、全文の証明を Lean に移植済みではない。
追加文献の PDF バイトハッシュは今回固定していない。実際の外部定理利用前に版・ハッシュ・証明依存を再取得する。

### R6 — solver 変種・平均・乱数（M04、M06、M08）

Algorithm 1（p6）、Algorithm 2と補助手続（p15）、Appendix H–J の操作を別項目にした。
current-policy leaf PBS、average-policy leaf PBS、reach-weighted average、単なる座標平均を区別する。
linear CFR、discounted CFR、vanilla CFR-D、CFR-AVG、modified CFR-AVG、FLOP、warm-start は
同じ関数名に隠さない。初期方策の重み、反復添字の0/1始まり、sampling support、
warm-start後に反復が残る条件も必要である。
Appendix Hの平均係数とGWFP証明側の添字、SETLEAFVALUESの引数差も原文のまま追跡する。

Theorem 5 は exact continuation solve を使う。実験上の
`t*vhat(avg_t)-(t-1)*vhat(avg_(t-1))` という差分更新の一般保証を同定理から推論しない。
この modified 版は後続段階で証明と反例の両方を探索する。未解決との文献上の記述だけで放棄しない。
全体で一度選ぶ iteration と各行動で選び直す iteration は異なる law であり、
共有/私的 seed と相手の観測可能性、探索用データ履歴とbelief更新の条件付けも分ける。

### R7 — 候補の signature と前提（M02以降）

[`inventory/reuse.json`](inventory/reuse.json) は元台帳が候補に挙げた全17モジュールについて、
23宣言の完全修飾名、実際の source range、モジュール全体のSHA-256、前提レビューを保持する。
周囲の `variable` もハッシュ対象であり、抜粋を elaborated type と偽っていない。
`check_inventory.py --lean` はそれらを import し、実コンパイラの `#check` 出力を記録する。
存在と型が確認されても全候補を `candidate_not_applied` に保つ。

特に、ExecutionProtocol の progress は停止性ではない。historyFintype は有限Stateとtree-shaped性を要求し、
有限worldを同一視して履歴を潰してよいとは言わない。FOSG.Game は Protocol と情報モデルの薄い包装であり、
PBS・utility・有限horizonの証明を持つという意味ではない。
behavioral/mixed変換には ActsOnceWhereItMatters / ConstrainsAlike が必要で、
play分布の一致だけでは unilateral deviation の対応は得られない。

局所 CFR matcher は `hrealize` を全 law/environment について、`hbound` を一様に要求する。
root-regret 定理には同じ process を使う有限siteのscheduler、reachの[0,1]制約、
全deviation・時刻についての `hgain` 分解が必要で、極限版には `hlocal` も要る。
これらを structure に仮定として置くだけではReBeLの全ゲーム証明は完了しない。
minimax には有限非空の純粋戦略carrierと二人零和性が必要である。
matrix-value の一様 entrywise error はtypeごとの oracle contractとは別物であり、
ZeroSumLearning の epsilon は双方の external-regret bound の和である。
FictitiousPlay の既存定義は一様なempirical更新であり、FLOP/GWFPの一般収束を提供しない。
