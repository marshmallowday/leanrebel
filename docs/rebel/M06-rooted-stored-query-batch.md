## Definitions and guarantees

PBSRootStoredValue defines pbsRootPublicPosterior from the actual rooted trunk
prefix. It retains all publicly matching atoms, including stopped histories.
pbsRootStoppedFraction is stopped public mass divided by the same public reach.
A possible factual live child supplies positivity. There is no zero-probability
posterior and no claim that the ratio is small.

pbsRootDecoded_public_error pushes both public and live joint laws through the
existing child readout and any single original continuation kernel:
absolute expectation difference <= 2*bound*stoppedFraction.
It does not compare independently changed kernels.

pbsRootStored_fresh_value derives BOTH Nash premises from actual recursive
solvers, one internal rooted live child and one original solver on the decoded
unfiltered public law. A common fixed-profile error and cross deviations yield
scalar gap <= internalError+freshError+2*bound*stoppedFraction.
Cuts/noise/fallback/errors may differ. Each cuts.sum must equal remaining;
the profiles themselves are never rewritten or equated.

pbsRootStored_fresh_security uses the actual finite fresh private draw against
a fixed seed-blind original opponent. Relative to the decoded internal scalar,
its allowance is internalError+2*freshError+2*bound*stoppedFraction.
The second freshError is the fresh solver's own security allowance.
Execution uses the decoded public MODEL root law. This is not a claim about an
unknown opponent's factual history law or an individual seed's Nash property.

PBSRootStoredState projects an optional saved joint law without changing the
native state, its private memory or selected incumbent. Missing stays missing.
pbsRootComposed_stored_law consumes the actual composed selected-round prefix
theorem. pbsRootComposed_stored_query_law identifies its readout with exactly
the decoded public PBS used above, via equality of conditioning events; it
does not transport dependent PBS values by equating unrelated indices.

The initial prior.law=pure init premise is for this same rooted protocol's own
initial run. It does not permit resetting a carried noninitial prior.
State.history and its dependent stored belief remain intact. A shaped public
observation is explicit, not inferred from a single hidden-history support fact.
