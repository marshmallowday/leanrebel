## Actual execution, not a substituted model law

cfrDWeightedEnvelopeLoss is an expectation under privateCarriedPrefix. The
selected private iteration and its reached original-game history remain JOINT.
Perfect recall and unilateralReference_density transfer a reference query's
conditional envelope to this actual prefix against any fixed unknown behavioral
opponent. This uses neither equality between a model PBS and an unknown-opponent
posterior, nor independent resampling of the seed and history, nor a worst-case
inverse reach multiplier.

The new cfrDFreshTransportCharge is zero on stopped queries. On live queries it is

    finalChildLoss + max(0, freshValueChange) + 2*B*conditionalTransportDefect.

freshValueChange is the signed new-minus-old continuation model value on the OLD
reference fiber. conditionalTransportDefect is the already proved OLD/NEW
conditional atom L1 cost on common support. A query lost from NEW support costs
one without evaluating a fictitious NEW fallback posterior. No OLD/NEW reference
equality, information-local density or support inclusion is required by the
new generic query-envelope theorem. Payoffs are bounded in absolute value by B.

The actual cost depends on the unknown opponent through its visitation law.
cfrDWeightedTransportLoss_le_uniform proves that it never exceeds the previous
uniform final-child/value-drift/transport allowance. Keeping the other data fixed,
that comparison recovers an opponent-independent allowance. The sharp finite-law
control charges a cost of two visited with probability 1/100 by only 1/50.

## Constructed solver consumer and explicit assumptions

cfrDDepth_fresh_weighted_security consumes the existing depth-limited parent's
actual focal full regret and opponent prefix regret, plus the derived query
envelopes. Its generic boundary still exposes ordinary parent-oracle contracts
and NEW local child quality; it does not assume the final security conclusion.

cfrDFreshChain_weighted_security closes those generic solver premises using the
ACTUAL noisy sampled-information parent and the finite chain of recomputed
information-set children. Oracle accuracy and child quality are derived, not
stored as certificates in solver input. The root comparison equilibrium only
names the original game's security value; no algorithm consumes it.

The allowance remains

    C_error*predictionError + C_time/sqrt(T) + oldChildLoss
      + E_actualPrefix[1_live *
          (finalChildLoss + positiveValueChange + 2*B*conditionalTransport)].

Assumptions are finite legal-history/action/menu carriers, bounded zero-sum
history payoffs, positive finite outer iteration count, nonnegative prediction
allowance with its explicit pointwise noise bound, positive old-child and last
fresh-child tolerances, and an arbitrary fixed seed-blind behavioral opponent.
Perfect recall and the observation clock for the constructed consumer come from
the existing full-observation model. Earlier fresh stages need only be legal;
only the last stage's positive tolerance is used for the final local quality.

The resolver is the existing private legal-plan draw of the FINAL computed
average, whose original-history law is already established. It is not the
separate native-CFR-iteration child sampler. No individual CFR iterate is
assumed Nash. This real-valued specification is not a floating-point runtime
or a proof of learned-network accuracy.
