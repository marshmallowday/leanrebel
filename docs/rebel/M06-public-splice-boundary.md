# M06: an entirely unvisited public state is not a factual posterior

This additional source keeps the previously supplied all-query-Nash interface
but proves a more applicable root-case interface separately. The old theorem
is not silently reinterpreted as covering an impossible factual own-type law.

`cfrDPublicResponseCompletion_value_of_root_cases` computes the conditional
optimum at a zero-own-reach root without a Nash premise. At a positive-own-reach
root it instead uses a supported type of a canonical PBS Nash profile.
`cfrDPublicResponseCompletion_live_leafOptimal` only requests that Nash witness
when the queried live information state genuinely belongs to factual support.
The opposite branch obtains zero own reach from actual reference sampling and
uses the constructed finite conditional best response. Both branches derive
the same all-deviation CFRDLeafOptimal zero-loss contract.

An entirely unvisited public state may still be in the unilateral reference
packet. Requiring every reference query to have a corresponding positive type
in a factual mixture would exclude this case. Two new HiddenTypes declarations
check absence of the complete public history from factual play and its presence
in the actual unilateral reference law. Together with the existing five public
splice controls, these test the distinction rather than discarding the boundary.
