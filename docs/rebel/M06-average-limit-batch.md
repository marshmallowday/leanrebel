## Source obligation and batch boundary

[Main paper, page 6, section 5.1](https://papers.nips.cc/paper/2020/file/c61f571dbd2fb949d3fe5ae1608dd48b-Paper.pdf)
distinguishes the average policy's convergence from the final iteration
and uses the uniform average of the per-iteration root value vectors.
The existing accepted target arithmetic handles the latter. This batch
addresses the missing fixed-trace epsilon-N policy guarantee.
It uses the main uniform scheme, not supplemental linear weighting or warm start.

The implementation is grouped from scalar threshold through regret bounds,
constructed exact/noisy children, PBS decoding, the actual recursive parent,
concrete hidden-type examples, and independent rational negative controls.
Fresh re-solving safety is a separate boundary because it needs small signed
replacement costs and model-posterior comparisons that policy Nash accuracy
does not imply. It is not deferred simply by file or lemma size.

## Mathematical guarantees

For a fixed oracle and its full infinite learning trace, let
F = (Cerror0 + Cerror1) * error + 2 * loss and C = Cfinite0 + Cfinite1.
The threshold floor((abs(C)/epsilon)^2)+1 is positive, and every later count T
satisfies C/sqrt(T) <= epsilon. The existing own-reach average therefore
satisfies IsNash with tolerance F+epsilon against every behavioral deviation.
The result does not assume exploitability decreases at every iteration.

CFRDAverageLimit constructs the threshold and exposes both an all-later-count
bound and a quantified epsilon-N statement. For the existing constructed
exact oracle, error=loss=0 yields vanishing Nash error on one trace. Its factual
child equilibria and off-path completion are constructed internally, not
provided as a desired-conclusion premise. This ideal backend remains
noncomputable; it is not described as the executable finite-child solver.

For the actual information-local finite-child oracle, fixed error and positive
child tolerance remain an explicit floor. PBSAverageLimit transports this
all-later-count guarantee through the existing original-game PBS decoder,
preserving the correlated joint root law and cut+1 administrative fuel.

pbsRecursiveParentAverage varies only the outer iteration count. The recursive
tail, allocation, child tolerance, predictor and its infinite trace remain
fixed. Its allocated-count identity recovers the unchanged pbsRecursiveDepth.
The all-later-count proof discharges smaller-solver accuracy by the existing
structural recursion theorem, rather than asking for recursive Nash evidence.
The recursive statement retains positive noise and child loss; it does not
incorrectly claim exact convergence just by increasing the outer count.

Nash-error convergence is not a proof of convergence to a specified equilibrium
profile, of the last iterate, or of a learned network. Nor does the result prove
convergence of numerical value targets to an equilibrium value vector. Stored
model beliefs are never equated with an unknown opponent's actual posterior.
The printed R5 expression remains separate from the corrected additive
finite-time bound, and the child tolerance term is retained.

## Concrete checks and validation surface

Examples use the canonical hidden-type game: the live-child exact driver,
the actual noisy three-level recursive parent, its allocated identity, and
the zero-coefficient nonempty threshold.

floors, cycling final policies and nonmonotone average exploitability, trace
prefix consistency versus a horizon-dependent oracle, and fixed recursive
allocations. The matching-pennies cycle is an independent mathematical
counterexample control, not a claim that this sequence is generated by CFR.
