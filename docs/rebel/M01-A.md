## Mathematical scope and semantic review

The source of this slice is ROADMAP.md risk R3 at the M00 bootstrap, not an
unqualified assertion that the paper itself has been refuted. The module is
`GameTheory/Tests/ReBeLSourceDiagnostics.lean`, namespace
`GameTheory.ReBeL.SourceDiagnostics`.

Let f(x,y)=x/(x+y), b=(1/2,1/2), g=(1/2,-1/2), z=(1/2,3/2), over rationals.
The affine plane is f(b)+g dot ((x,y)-b).

| Declarations | Meaning and controls |
|---|---|
| `normalizedCoordinate`, `centeredPlane` | Exact rational arithmetic definitions, not floating point |
| `simplex_plane_agrees` | Assumption x+y=1 only; proves equality on the affine simplex |
| `anchor_value`, `simplex_positive_control` | Interior anchor and a noncentral positive control |
| `simplex_boundary_control` | The simplex boundary point (1,0), with nonzero total mass |
| `witness_positive`, `witness_not_on_simplex` | Both witness coordinates strictly positive; sum is not one |
| `witness_value`, `witness_plane`, `supporting_inequality_fails` | Actual value 1/4, plane zero, strict violation of the proposed support inequality |
| `not_global_support` | Refutes the universal supporting inequality on the positive cone for these definitions |
| `midpoint_jensen_fails` | Midpoint value 1/3 is strictly below endpoint average 3/8 |
| `origin_excluded` | Zero mass is not an admissible positive-cone input; Lean's total division is not probabilistic normalization |

All constant diagnostics have no additional hypotheses. No game, PBS,
