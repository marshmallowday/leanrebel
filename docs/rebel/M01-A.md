## Mathematical claims and controls

Let f(x,y)=x/(x+y), b=(1/2,1/2), g=(1/2,-1/2), and z=(1/2,3/2), over rationals.
The file proves f(z)=1/4, the proposed affine supporting plane at z is zero,
and the inequality f(z)<=plane(z) is false although both coordinates of z
are positive. It also proves agreement on x+y=1 (including a boundary control),
a noncentral simplex control, exclusion of the zero-mass origin, and a strict
midpoint Jensen violation on the positive cone.

This distinguishes simplex support from global positive-cone support. It does
not identify a game-level PBS value, prove differentiability, embed the example
in the paper's game model, or refute every reading of Theorem 1. Those semantic
questions remain M01-B/M05 obligations; the parent VAL-THEOREM1 must not be
marked verified or refuted merely from this diagnostic.

## Reproduction

```text
lake env lean --version
lake build GameTheory.Tests.ReBeLSourceDiagnostics
python scripts/rebel/audit_axioms.py
lake build
lake lint
pwsh -File scripts/phase1-audit.ps1 -VerifyExpected
pwsh -File scripts/phase2-audit.ps1 -VerifyExpected -DeepReachability
pwsh -File scripts/phase3-audit.ps1 -VerifyExpected -DeepReachability
python scripts/rebel/check_coverage.py
```

The dedicated workflow has read-only contents permission, pinned actions,
a timeout, branch-local concurrency and no persisted checkout credentials.
The auditor uses the pinned Lean.collectAxioms API. Its only allowed axioms are
propext, Classical.choice and Quot.sound. A source grep is not this audit.
Generated inspection commands live under ignored .lake, not in build modules.
